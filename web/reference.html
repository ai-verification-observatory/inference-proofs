Rerun by a weights holder

What one proof establishes

  1. Weights hidden

    No

    The checker holds the weights: recompute needs them.

  2. Model bound

    Yes

    Reruns the pinned model files and compares every claimed token.

  3. Whole output proved

    Yes

    One forward pass over prompt plus every claimed output token.

  4. Formally verified

    No

    A rerun, not a proof: no security argument, by definition.

  5. Security level

    No

    A rerun, not a proof: no soundness level, by definition.

  6. No trusted party

    Yes

    The checker holds the weights and reruns the model itself.

kind
Someone reruns the work: a referee settles a dispute between providers, or a checker holding the weights recomputes.
