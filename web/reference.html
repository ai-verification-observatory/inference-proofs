    Plain serving

    What one proof establishes

    1. Weights hidden. Does the checker learn nothing about the weights?

      No

      No checker, so nothing to hide from: no assurance, by definition.

    2. Model bound. Is each checked token tied to the committed weights?

      No

      Outputs are recorded, never compared with anything.

    3. Whole output proved. Does one check cover every output token of a request?

      No

      Plain serving proves nothing: no assurance, by definition.

    4. Formally verified. Is the security argument checked by a proof assistant?

      No

      Plain serving proves nothing: no assurance, by definition.

    5. Security level. Is a soundness level stated, and proven?

      No

      Plain serving proves nothing: no assurance, by definition.

    6. No trusted party. Does a check hold without trusting a chip maker, a setup ceremony or an honest party?

      No

      Nothing is checked; the reader trusts the provider.

    Rerun by a weights holder

    What one proof establishes

    1. Weights hidden. Does the checker learn nothing about the weights?

      No

      The checker holds the weights: a rerun needs them.

    2. Model bound. Is each checked token tied to the committed weights?

      Yes

      Reruns the pinned model files and compares every claimed token.

    3. Whole output proved. Does one check cover every output token of a request?

      Yes

      One forward pass over prompt plus every claimed output token.

    4. Formally verified. Is the security argument checked by a proof assistant?

      No

      A rerun, not a proof: no security argument, by definition.

    5. Security level. Is a soundness level stated, and proven?

      No

      A rerun, not a proof: no soundness level, by definition.

    6. No trusted party. Does a check hold without trusting a chip maker, a setup ceremony or an honest party?

      Yes

      The checker holds the weights and reruns the model itself.

    kind
    Someone reruns the work: a referee settles a dispute between providers, or a checker holding the weights reruns it.
