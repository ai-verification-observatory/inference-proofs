    What one proof establishes

    • Weights hiddenDoes the checker learn nothing about the weights?
    • Model boundIs each checked token tied to the committed weights?
    • Whole output checkedDoes one check cover every output token of a request?
    • Formally verifiedIs the security argument for this configuration checked by a proof assistant?
    • Security levelIs a soundness level stated for this configuration, and proven?
    • No trusted partyDoes a check hold without trusting a chip maker, a setup ceremony or an honest party?
