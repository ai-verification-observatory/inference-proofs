    We believe a claim about which AI model answered should come with evidence anyone can afford to check.

    When a service says a reply came from a given AI model, you normally have to take its word. A proof of inference is a file that lets anyone check that claim without running the model. This site tests the systems that make such proofs. It measures how much more a proved reply costs than serving the same reply without a proof, and whether each system's checker refuses a proof once the model, the prompt or the reply is changed. Every system gets the same request on the same kind of GPU, and we run each one as published, with no change to its code.

    Why a claim about an AI system needs evidence: Why verify.

    What we do

    As published
    Run each system at a fixed public version, with no change to its code and no setting its documentation does not name.
    Same request
    Give every system the same request. The prompts come from a public random draw made after the rules are frozen, so nobody, us included, picks them or sets a rule knowing them.
    Every run
    Record every run of a release, failed ones with their error code and last lines of output. Report ranges and sample sizes, never a single best run.
    Computed
    Compute every check result from stored records. No reviewer sets one by hand.
    Confirmed
    Before we publish that a system's checker accepted a changed model, prompt or reply, reproduce it with the system's own command, outside our own code. Until then the check reads undecided and we tell the system's publisher.

    What we do not do

    Payment
    Take payment for a listing, a place in the ranking or a rerun.
    Building
    Build these systems or certify them.
    Security
    Test whether a proof can be forged or whether it keeps the model's weights hidden. No check attempts a forged proof.
    Across models
    Rank systems across models. Each model has its own ranking, of the systems that passed the six checks.

    Who runs it

    Operator

    Conflicts

    How to check us

    Sources
    Every figure shows its unit, what was timed and its sample size, and names the source it came from.
    Open code
    The rules, the code we use to run each system and the measuring code are public.
