    We believe a claim about which AI model answered should come with evidence anyone can afford to check.

    MandateWhat we doWhat we do not doWho runs itHow to check us

    When an AI service tells you that a reply came from a specific model, you normally have to take the operator's word for it. A proof of inference is a cryptographic receipt that lets anyone verify that claim without re-running the model. This benchmark tests the systems that build those proofs. On a ladder of open-weights models, we measure how much more it costs to generate a proved reply than to serve the same reply normally, and we test whether each system's verifier actually rejects the proof when we tamper with the model, the prompt, or the reply. Every system receives the same request on the same class of hardware, running the publisher's unmodified code.

    What we do

    As published (new tab)
    We run each system at a pinned public commit, with no patches to its source code and no flags or settings that are not documented by its publisher.
    Same request (new tab)
    We give every system on a model the exact same request. The prompts are drawn from a public randomness beacon after the benchmark rules are frozen, so neither we nor any system author can cherry-pick prompts or tune rules around them.
    Every run (new tab)
    We publish every run we execute for a release, including crashes and failed checks, complete with exit codes and log tails. We report full session ranges and sample sizes, never a single cherry-picked run.
    Computed (new tab)
    We compute every check outcome, ratio, and summary automatically from the stored run records; no reviewer sets a check state or types a number by hand.
    Confirmed (new tab)
    Before we publish that a system's verifier accepted a tampered model, prompt, or reply, we reproduce that failure with the system's own command line, outside our harness. Until we confirm it, the check is marked undecided and we notify the publisher.

    What we do not do

    Payment
    We do not accept payment for listing a system, ranking it, or running a benchmark session.
    Building (new tab)
    We do not build or sell a prover of our own, and we do not certify the systems we test.
    Security (new tab)
    We do not attempt to cryptographically forge proofs or extract hidden weights. Our six checks test what an external harness can observe; for mathematical soundness and zero-knowledge claims, we quote what the publisher's own documentation states.
    Across models (new tab)
    We never rank systems across different models. Each model on the ladder has its own table, and only the systems that pass all six checks on that model are ranked in it.

    How to check us

    Sources (new tab)
    Every number on this site carries its unit, timing scope, sample size and the stored record it was computed from. A system's page prints them.
    Open code (new tab)
    All of our benchmark rules, system adapters, measurement scripts, and raw run records are open source in our public repository.
    Level 1 (new tab)
    Frozen 2026-11-11. The models, the request, the constants of the checks and the order rule are one file. It does not change once frozen: a change of rule is a new level.
