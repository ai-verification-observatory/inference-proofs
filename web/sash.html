    What one proof establishes

    1. Weights hidden. Does the checker learn nothing about the weights?

      Not stated

    2. Model bound. Is each checked token tied to the committed weights?

      Yes

      Each matrix product checked against pinned weights; each token is the top choice.

    3. Whole output proved. Does one check cover every output token of a request?

      Yes

      One statement per request: every prompt position and the whole continuation.

    4. Formally verified. Is the security argument checked by a proof assistant?

      Not stated

    5. Security level. Is a soundness level stated, and proven?

      Partly

      Level stated as conjectured, in a source code comment.

    6. No trusted party. Does a check hold without trusting a chip maker, a setup ceremony or an honest party?

      Not stated
