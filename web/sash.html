    What one proof establishes

    1. Weights hidden. Does the checker learn nothing about the weights?

      Not stated

      source: how we read Weights hidden

    2. Model bound. Is each checked token tied to the committed weights?

      Yes

      Each matrix product checked against pinned weights; each token is the top choice. source: how we read Model bound

    3. Whole output checked. Does one check cover every output token of a request?

      Yes

      Every prompt and generated position is checked across the joined grid of segment proofs. source: how we read Whole output checked

    4. Formally verified. Is the security argument for this configuration checked by a proof assistant?

      Not stated

      source: how we read Formally verified

    5. Security level. Is a soundness level stated for this configuration, and proven?

      Partly

      Level stated as conjectured, in a source code comment. source: how we read Security level

    6. No trusted party. Does a check hold without trusting a chip maker, a setup ceremony or an honest party?

      Partly

      The fixed statement is produced at setup and trusted by the verifier. source: how we read No trusted party
