inference-proofs

An open benchmark for provable inference: the same models, the same reference hardware, the same timing rules, and a claim card saying what each proof establishes. It measures provers; it does not build, rank or certify them.

It reports what each system states it proves, how long proving and verifying took under stated scopes, and what the negative controls returned. It does not report a combined score, and a number is "measured" on this site only when it was reproduced.
