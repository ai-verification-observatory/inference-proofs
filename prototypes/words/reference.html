Rerun by a weights holder

Re-executed Someone reruns the work: a referee settles a dispute between providers, or a checker holding the weights recomputes.

What one proof establishes

YesPartlyNoNot statedDraft criteria, needs an RFC →

  1. Weights hidden

    Does the checker learn nothing about the weights?

    No

    The checker holds the weights: recompute needs them.

    “A verifier holding the weights checks a claimed output by running the model itself.”
    rfcs/0015-reference-rows.md L82 · fbe1f9c7 · this repository ↗

  2. Model bound

    Is each checked token tied to the committed weights?

    Yes

    Reruns the pinned model files and compares every claimed token.

    “A reference loads only the workload's pinned model files (RFC-0003), never another checkpoint of the model”
    rfcs/0015-reference-rows.md L102 · fbe1f9c7 · this repository ↗
    More quotes · Our note
    • “Each position is agree when the argmax equals the claimed token, else disagree.”
      rfcs/0015-reference-rows.md L86 · fbe1f9c7 · this repository ↗

    • Amber for a configuration that declares a precision substitution (PM-2, RFC-0015 L104); agreement is reported and changes no verdict (RC-6).

  3. Whole output proved

    Does one check cover every output token of a request?

    Yes

    One forward pass over prompt plus every claimed output token.

    “for each request, the engine runs one forward pass over prompt plus the system's claimed output tokens and takes the argmax at each claimed output position”
    rfcs/0015-reference-rows.md L86 · fbe1f9c7 · this repository ↗
    More quotes
    • “positions after the first disagreement are still compared under teacher forcing”
      rfcs/0015-reference-rows.md L98 · fbe1f9c7 · this repository ↗

  4. Formally verified

    Is the security argument checked by a proof assistant?

    No

    A rerun, not a proof: no security argument, by definition.

    “Reference systems have no claim.yaml (they prove nothing)”
    rfcs/0015-reference-rows.md L45 · fbe1f9c7 · this repository ↗

  5. Security level

    Is a soundness level stated, and proven?

    No

    A rerun, not a proof: no soundness level, by definition.

    “Reference systems have no claim.yaml (they prove nothing)”
    rfcs/0015-reference-rows.md L45 · fbe1f9c7 · this repository ↗

  6. No trusted party

    Does a check hold without trusting a chip maker, a setup ceremony or an honest party?

    Yes

    The checker holds the weights and reruns the model itself.

    “A verifier holding the weights checks a claimed output by running the model itself.”
    rfcs/0015-reference-rows.md L82 · fbe1f9c7 · this repository ↗
    Our note

    • Trust in the checker's own engine and GPU is shared by every row and not counted.
